# Space Debris Tracking, Collision Risk & Mitigation Management System

Academic Java + DBMS project using simulated data.

## Stack
- Java 17
- Maven
- JDBC + MySQL Connector/J
- MySQL 8.x
- JavaFX

## Structure
- `database/schema.sql` - schema with constraints and FKs
- `database/sample_data.sql` - simulated sample data
- `database/queries.sql` - report queries and dashboard view
- `src/main/java/com/spacedebris` - layered Java code

## Build and Test
```bash
mvn test
```
